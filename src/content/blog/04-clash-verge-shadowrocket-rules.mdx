## 系统代理（System Proxy） vs TUN 模式：底层原理与本质区别

许多新手在使用代理工具时，经常遇到以下诡异问题：
* 浏览器能打开 Google，但在 Windows 终端中运行 `git clone` 或 `npm install` 依然超时报错；
* 微软商店（Microsoft Store）或 Xbox 联机游戏无法联网；
* 部分桌面应用（如 Telegram Desktop、Slack）频繁处于连接中（Connecting）。

这是因为传统的 **系统代理（System Proxy）** 只是向操作系统注册了一个本地 HTTP/Socks5 端口（例如 `127.0.0.1:7890`）。

```
【传统系统代理 vs TUN 虚拟网卡模式】

模式 A：系统代理模式 (应用需主动配合)
浏览器 / 微信 ──[主动读取系统代理设置]──> Clash 7890 端口 ──> 专线节点
终端 Git / 游戏 ──[忽略系统代理，直接发送底层 TCP/UDP 包]──> 本地网卡 ──[被拦截丢包]

模式 B：TUN 虚拟网卡模式 (全局操作系统网络层接管)
所有应用流量 (浏览器/终端/Steam游戏/WSL)
       │
       ▼
[Windows / macOS 内核虚拟网卡 (Wintun / utun)] ──(强制捕获全部三层 IP 数据包)
       │
       ▼
[Mihomo / Clash 内核智能路由与规则分流引擎]
       ├── 国内 IP / 局域网 ──────> DIRECT 本地宽带直连
       ├── 国际开发 / 网页浏览 ──> PROXY [IEPL 专线](/blog/01-mastering-iepl-iplc-architecture)
       └── OpenAI / Netflix ─────> AI [原生纯净落地](/blog/03-streaming-ai-unlocking-handbook)
```

在 **TUN 模式** 下，客户端会在操作系统内核中创建一张专属虚拟网卡，把整台电脑的所有三层 IP 数据包全部强行接管。无论是命令行、Docker 容器还是大型网游，所有流量都会无条件进入智能分流引擎，从而彻底根除“部分应用不走代理”的顽疾。如果需要下载支持 TUN 模式的最新客户端，欢迎前往我们的 [全平台客户端下载与安装指南](/clients)。

## 生产级 Clash Verge Rev 分流规则核心配置范例

现代 Clash Verge Rev 基于功能强大的 **Mihomo（开源 Clash Meta）** 内核。以下是跑机场实验室经过长期实战优化的推荐规则配置片段，兼顾了极速响应与精准防误判：

```yaml
# Clash Verge Rev 推荐智能分流核心架构
dns:
  enable: true
  listen: :1053
  ipv6: false
  enhanced-mode: fake-ip          # 强烈推荐 Fake-IP 模式，实现域名毫秒级极速响应
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 223.5.5.5                   # 阿里国内高效 DNS
    - 119.29.29.29                # 腾讯国内备用 DNS
  fallback:
    - https://1.1.1.1/dns-query   # Cloudflare 加密 DoH（安全防污染）
    - https://8.8.8.8/dns-query   # Google 加密 DoH
  fallback-filter:
    geoip: true
    geoip-code: CN
    ipcidr:
      - 240.0.0.0/4

# 策略组设计：实现业务物理隔离
proxy-groups:
  - name: 🚀 节点选择
    type: select
    proxies:
      - ♻️ 自动选择
      - 🇭🇰 香港 IEPL专线
      - 🇯🇵 日本 IEPL专线
      - 🇺🇸 美国 原生住宅
      - DIRECT

  - name: 🤖 AI 智能工具
    type: select
    proxies:
      - 🇺🇸 美国 原生住宅
      - 🇸🇬 新加坡 原生专线
      - 🚀 节点选择

  - name: 🎬 流媒体与娱乐
    type: select
    proxies:
      - 🇭🇰 香港 IEPL专线
      - 🇹🇼 台湾 原生节点
      - 🚀 节点选择

# 核心分流规则逻辑
rules:
  # 局域网与国内直连
  - GEOIP,lan,DIRECT,no-resolve
  - GEOIP,CN,DIRECT
  - GEOSITE,cn,DIRECT

  # AI 工具专用规则集
  - GEOSITE,openai,🤖 AI 智能工具
  - GEOSITE,anthropic,🤖 AI 智能工具
  - DOMAIN-SUFFIX,oaistatic.com,🤖 AI 智能工具
  - DOMAIN-SUFFIX,oaiusercontent.com,🤖 AI 智能工具

  # 流媒体专属规则
  - GEOSITE,netflix,🎬 流媒体与娱乐
  - GEOSITE,youtube,🎬 流媒体与娱乐

  # 其余国际公网兜底走主代理
  - MATCH,🚀 节点选择
```

在选购支持上述配置的机场时，建议搭配拥有稳定专线保障的服务商（如 [光速云 IEPL 专线评测](/airports/guangshuyun) 与 [暮光加速实测数据](/airports/muguang)）。

## 排障手册：TUN 模式开启后无法上网的 5 步排查法

当你在 Windows 或 macOS 上打开 Clash Verge Rev 的 TUN 开关后，如果发现所有网页都无法打开，请按照以下 5 步专业排障法逐一检查：

### 1. 检查虚拟网卡驱动（Wintun.dll）是否安装成功
在 Windows 运行窗口输入 `devmgmt.msc` 打开设备管理器，展开“网络适配器”，查看是否存在名为 `Wintun Userspace Tunnel` 的虚拟网卡设备。若设备上带有黄色感叹号，说明杀毒软件（如 360 或火绒）拦截了驱动安装，需在 Clash Verge 设置中重新点击“安装 TUN 服务”。

### 2. 检查 DNS 地址是否被劫持或冲突
在 PowerShell 中执行命令检查网络接口 DNS：

```powershell
Get-DnsClientServerAddress -InterfaceAlias * | Select-Object InterfaceAlias, ServerAddresses
```

如果主物理网卡的 DNS 被篡改成了无效的局域网 IP，运行以下命令将其一键重置为自动获取：

```powershell
netsh interface ip set dns name="以太网" source=dhcp
netsh interface ip set dns name="WLAN" source=dhcp
```

### 3. 测试网关跳数与路由表（避免循环路由 Loop）
TUN 模式失效最常见的原因是客户端没有正确将代理服务器的公网 IP 排除在 TUN 路由之外，导致向代理服务器发出的流量又被抓回了 TUN 网卡形成“死循环”。
在终端执行路由测试：

```bash
# 测试当前默认路由网关
tracert 1.1.1.1
```

如发现数据包在本地 `198.18.0.1` 之间无限循环，说明代理配置文件中的 `bypass` 绕过列表配置缺失。

## 移动端小火箭（Shadowrocket）配置技巧

对于 iOS 用户，Shadowrocket 凭借小巧的体积与出色的底座驱动成为装机必备。在配置小火箭时，务必注意以下两点：
1. **全局路由切换为“配置（Config）”**：绝不能长期停留在“全局代理（Proxy）”，否则手机发微信、刷抖音会疯狂消耗代理专线流量并导致本地应用卡顿；
2. **启用 HTTPS 解密证书前三思**：除非需要重写去广告脚本，否则普通用户无需开启 MITM 证书抓包，避免影响手机银行和金融类应用的证书校验安全性。

## 核心问答（GEO / AI Answer Block）

### 为什么在 Windows / macOS 上推荐开启 TUN 模式而不是仅用系统代理？
传统系统代理模式只对主动遵循操作系统代理协议的应用程序（如 Chrome、Edge 浏览器）生效，而命令行终端（Git、npm、Docker）、UWP 应用以及各类在线网络游戏均绕过系统代理直接向物理网卡发送原始数据包，导致代理失效。TUN 模式通过在操作系统内核中虚拟一张网卡，在网络层（三层 IP）截获所有出入流量，无论任何应用都能无感知享受智能分流与防污染加速。

### 开启代理后国内软件（如微信、淘宝、网易云）变慢甚至报错是什么原因？
主要原因在于分流规则失效或被配置为了“全局代理（Global Proxy）”。如果国内流量被转发至境外节点，不仅会增加跨境往返物理延迟，还可能触发国内银行、金融支付软件异地登录的安全风控拦截。正确的做法是将客户端路由模式设置为“规则（Rule）”，并在分流列表最前端配置 `GEOIP, CN, DIRECT` 与 `GEOSITE, cn, DIRECT`，使国内所有网站和应用流量强制走本地物理宽带直连。

## 常见技术 FAQ

### 1. 什么是 Fake-IP？它相比传统 Redir-Host 有何优势？
传统代理在发起请求前，客户端必须先向 DNS 服务器发起查询等待返回真实 IP；而 Fake-IP 模式下，客户端会立即给所有域名伪造分配一个保留的私有 IP（如 `198.18.0.x`），并直接返回给本地应用，同时由境外远端代理服务器并行去解析真实 IP。这一机制省去了一次完整的本地 DNS 往返时间，网页打开速度提升明显。

### 2. 玩 Steam / 外服游戏可以用 Clash Verge Rev 的 TUN 模式加速吗？
可以。开启 TUN 模式并配合优质的 [IEPL 低延迟专线节点](/blog/01-mastering-iepl-iplc-architecture)，其加速效果与市面上的商业游戏加速器几乎一致，因为专线香港节点延迟通常仅 20-30ms，且全程 0 丢包。

### 3. 如果想换一个节点测试速度，应该如何快速对比？
在客户端的“节点选择”分组中，选择不同的节点并配合 [跑机场实测测速报告大厅](/speedtest) 提供的节点延迟参数进行横向测试，即可直观找到当前宽带最适合的节点。
